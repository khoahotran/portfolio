Retry Strategy Visualizer

Visualize how different backoff algorithms distribute network retries over time.

Runs the real algorithm

The real backoff schedules, computed in your browser from your inputs: linear is base x attempt, exponential is base x 2^attempt, and full jitter replaces each delay with a uniform random value in [0, delay) — the AWS "Exponential Backoff and Jitter" formulation. The cumulative timeline is the actual sum of those delays, so what you see is what a client using this policy would wait.
